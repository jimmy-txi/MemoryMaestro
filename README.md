
# 🧠 MemoryMaestro

> **A captivating multiplayer memory game in Java!**

## 🚀 Features

- 👥 **2-Player Mode**: Play against a friend and compete for the highest score!  
- 🎲 **Randomized Board**: Each game generates a new random board layout.  
- 🕵️‍♂️ **Cheat Mode**: Reveal hidden cards to gain an advantage.  
- 💪 **Extreme Options**:  
  - **Hidden Mode**: Cards remain hidden even after a match attempt.  
  - **Letter/Number Mode**: Choose whether cards display letters or numbers.  
  - **Custom Grid Size**: Select from various grid sizes:  
    - `2x2`  
    - `2x3`  
    - `4x4`  
    - `6x4`  

## 🛠️ Installation

```bash
# Clone this repository
git clone https://github.com/your-username/MemoryMaestro.git

# Compile the project
javac -d bin src/*.java
```

## 🎮 How to Play

1. Launch the game.  
2. Choose the game mode (Solo or 2-Player).  
3. Select your preferred difficulty and grid size.  
4. Match pairs of cards to score points. Use cheat mode wisely if needed!  
5. Compete for the highest score, and have fun!
